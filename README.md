### Metro Auto Staff - Back End Repo

We built an AI voice assistant that leverages OpenAI speech-to-speech model together with the Stockholm Public Transport (SL) API to provide information to travellers within the Stockholm Metro, regarding travel routes, ticket types and more.

This is the back-end repo. We built the front-end using Lovable in a separate repo.
